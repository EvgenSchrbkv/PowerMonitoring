# Power Monitor — перший запуск пристрою

Ця інструкція описує, як підключити Power Monitor, налаштувати Wi-Fi та Telegram під час першого запуску.

> Як створити бота, отримати Bot Token та Chat ID — див. [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).

---

## 1. Підключення живлення

Підключіть до пристрою:

1. **Батарею живлення**
2. **Блок зарядки**
3. **Кабель USB-C**

## 2. Увімкнення

Переведіть **перемикач живлення** в положення **«Увімкнено»**.

## 3. Підключення до Wi-Fi

Після увімкнення пристрій створить власну точку доступу Wi-Fi:

| Параметр | Значення |
|---|---|
| SSID | `POWER-MONITOR` |
| Пароль | `PowerSetup123` |

1. Підключіться до цієї мережі з телефона або комп'ютера.
2. У списку доступних мереж оберіть **свою домашню точку доступу Wi-Fi**.
3. Введіть **пароль** від неї.

Пристрій підключиться до вашого Wi-Fi.

## 4. Сторінка налаштувань

Відкрийте в браузері одну з адрес:

- `http://power-monitor.local/setup`
- `http://IP-АДРЕСА-ESP32/setup`

> Якщо адреса `.local` не відкривається (буває на деяких Android-пристроях і в деяких мережах), використовуйте IP-адресу пристрою. Її можна знайти в списку клієнтів роутера.

**Логін:** `admin`
**Пароль:** `admin`

## 5. Налаштування Telegram

На сторінці налаштувань заповніть поля:

| Поле | Що вводити |
|---|---|
| **Bot Token** | токен бота від BotFather |
| **Chat ID** | ID особистого чату і/або груп, **через кому** |

Можна вказати **кілька груп**, наприклад:

```text
5211223667, -5111224452
```

- Особистий чат — додатне число.
- Група — від'ємне число (з мінусом).

Натисніть **«Зберегти налаштування»**.

## 6. Перевірка Telegram

Після успішного збереження натисніть окрему кнопку **«Перевірити Telegram»**. Вона перевіряє **всі введені Chat ID** і надсилає в кожен чат тестове повідомлення:

```text
🧪 ТЕСТ POWER MONITOR
```

### Приклад: усе працює

```text
🟢 5211522667 — особистий чат: повідомлення доставлено
🟢 -5112214452 — група: повідомлення доставлено

🟢 Telegram працює: 2 з 2 чатів доступні.
```

### Приклад: неправильний Chat ID

```text
🟢 5201182267 — особистий чат: повідомлення доставлено
🔴 5141114222 — HTTP 400: Bad Request: chat not found

🟠 Telegram працює частково: 1 з 2 чатів доступні.
```

У відповідні чати має прийти повідомлення **🧪 ТЕСТ POWER MONITOR**.

Позначки результату:

| Значок | Значення |
|---|---|
| 🟢 | чат доступний, повідомлення доставлено |
| 🔴 | помилка для цього чату (наприклад, `chat not found`) |
| 🟠 | Telegram-з'єднання працює, але не всі чати доступні |
