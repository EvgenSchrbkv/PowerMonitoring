# Налаштування Telegram-бота для PowerMonitoring

Ця інструкція описує, як створити Telegram-бота, отримати **Bot Token** та **Chat ID**, а також налаштувати групу для сповіщень.

---

## 1. Створення бота (BotFather)

1. Відкрийте Telegram і знайдіть **[@BotFather](https://t.me/BotFather)** (офіційний бот з синьою галочкою).
2. Натисніть **Start** і надішліть команду:
   ```
   /newbot
   ```
3. BotFather запитає **назву бота** (відображається в чаті), наприклад:
   ```
   Power Monitoring
   ```
4. Потім запитає **username** бота. Він має бути унікальним і **закінчуватися на `bot`**, наприклад:
   ```
   my_power_monitoring_bot
   ```
5. Після успішного створення BotFather надішле повідомлення з **токеном**.

> Додатково (за бажанням): `/setdescription`, `/setuserpic`, `/setabouttext` — опис і аватар бота.

---

## 2. Bot Token

Токен виглядає приблизно так:

```
123456789:AAE_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

- Скопіюйте його і збережіть у безпечному місці.
- ⚠️ **Ніколи не публікуйте токен у GitHub** (у коді, README, issues). Хто має токен — той керує ботом.
- Якщо токен витік — у BotFather виконайте `/revoke` (оберіть бота), і отримаєте новий токен.
- Щоб знову побачити токен: `/mybots` → оберіть бота → **API Token**.

Зберігайте токен у секретах/конфігу, який не потрапляє в репозиторій (наприклад, `secrets.yaml`, змінна оточення або `.env`, доданий до `.gitignore`).

---

## 3. Chat ID

Chat ID — це числовий ідентифікатор чату, куди бот надсилатиме повідомлення.

### 3.1. Особистий чат (з вами)

1. Знайдіть свого бота в Telegram і натисніть **Start** (або надішліть будь-яке повідомлення). **Без цього бот не зможе вам писати.**
2. Відкрийте в браузері (підставте свій токен):
   ```
   https://api.telegram.org/bot<BOT_TOKEN>/getUpdates
   ```
3. У відповіді знайдіть блок `"chat"`:
   ```json
   "chat": {
     "id": 123456789,
     "first_name": "Evgen",
     "type": "private"
   }
   ```
4. Значення `id` — це ваш **Chat ID** (додатне число).

> Якщо `result` порожній (`[]`) — надішліть боту ще одне повідомлення і оновіть сторінку.

### 3.2. Альтернатива: через бота-помічника

Напишіть боту **[@userinfobot](https://t.me/userinfobot)** або **[@getidsbot](https://t.me/getidsbot)** — він відповість вашим ID.

## 4. Налаштування групи

### 4.1. Створення групи

1. У Telegram: **Нова група** → додайте учасників (можна тільки себе).
2. Додайте вашого бота до групи: відкрийте групу → **Додати учасників** → знайдіть бота за username.

### 4.2. Права бота

- Для простого надсилання повідомлень бот працює як звичайний учасник.
- Якщо бот має **читати команди/повідомлення** в групі або керувати нею — зробіть його **адміністратором** (група → Керування → Адміністратори → додати бота).
- Якщо бот не бачить повідомлень у групі, вимкніть Privacy Mode: у BotFather `/mybots` → бот → **Bot Settings** → **Group Privacy** → **Turn off**. Після цього краще видалити бота з групи та додати знову.

### 4.3. Отримання Chat ID групи

1. Надішліть у групу будь-яке повідомлення (для команд: `/start@your_bot_username`).
2. Відкрийте:
   ```
   https://api.telegram.org/bot<BOT_TOKEN>/getUpdates
   ```
3. Знайдіть `"chat"` з типом `group` або `supergroup`:
   ```json
   "chat": {
     "id": -1001234567890,
     "title": "Power Monitoring",
     "type": "supergroup"
   }
   ```
4. **Chat ID групи — від'ємне число** (для супергруп починається з `-100`). Копіюйте його **разом зі знаком мінус**.

> Якщо група перетворилась на супергрупу (наприклад, після зміни налаштувань історії чи додавання тем), її Chat ID зміниться — отримайте його заново.
> Або додайте @username_to_id_bot в свою групу і він повідомить Вам ваш ID і Chat ID.
