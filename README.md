# PowerMonitoring
Автономний монітор електропостачання на ESP32 з Telegram-сповіщеннями та веб-налаштуванням.  Power Monitor відстежує стан електромережі, фіксує відключення та відновлення електропостачання, зберігає статистику у пам'яті пристрою та надсилає сповіщення через Telegram.  Проєкт розрахований на автономну роботу.
