# ⚡ Power Monitoring

**Автономний монітор електропостачання на ESP32 з Telegram-сповіщеннями, веб-інтерфейсом та статистикою відключень.**

Power Monitoring — це автономний пристрій на базі ESP32, призначений для контролю наявності електропостачання.

Пристрій працює незалежно від Home Assistant та інших систем автоматизації. Він самостійно визначає зникнення та відновлення електроенергії, зберігає статистику та надсилає повідомлення через Telegram.

---

## ✨ Можливості

### ⚡ Контроль електропостачання

* визначення наявності електроенергії;
* фіксація моменту зникнення мережі;
* фіксація моменту відновлення;
* автоматичний розрахунок тривалості відключення;
* визначення поточної тривалості незавершеного відключення.

### 📊 Статистика

Power Monitor зберігає:

* кількість відключень;
* час останнього відключення;
* тривалість останнього відключення;
* загальний час без електроенергії;
* інформацію про незавершене відключення.

Дані зберігаються у NVS пам'яті ESP32 та не втрачаються після перезавантаження.

## 📱 Telegram

Power Monitor має вбудовану підтримку Telegram Bot API.

Бот може надсилати повідомлення:

* в особистий чат;
* у групу;
* одночасно в декілька чатів.

Для декількох Chat ID використовується запис через кому:

```text
5211583667,-5111414452
```

Для групового чату від'ємний знак `-` є частиною Chat ID.

### Повідомлення про відключення

```text
🔴 ЗНИКЛО ЕЛЕКТРОПОСТАЧАННЯ

🕐 Початок:
30.09.2026 10:15:20
```

### Повідомлення про відновлення

```text
🟢 ЕЛЕКТРОПОСТАЧАННЯ ВІДНОВЛЕНО

🕐 Початок:
30.09.2026 10:15:20

🕐 Відновлення:
30.09.2026 12:47:35

⏱ Без світла:
2 год 32 хв
```

## 🤖 Telegram-команди

Power Monitor підтримує команди Telegram-бота:

| Команда    | Призначення                        |
| ---------- | ---------------------------------- |
| `/start`   | список доступних команд            |
| `/status`  | поточний стан електропостачання    |
| `/last`    | інформація про останнє відключення |
| `/stats`   | статистика відключень              |
| `/time`    | поточний час                       |
| `/restart` | перезавантаження Power Monitor     |

Для групового чату команда також може мати формат:

```text
/status@nameyoubot
```

## 🌐 Web Setup

Power Monitoring має власну сторінку налаштування:

```text
http://IP-АДРЕСА-ESP32/setup
http://power-monitor.local/setup
```

На сторінці доступні:

* стан електропостачання;
* стан Wi-Fi;
* IP-адреса;
* поточний час;
* Bot Token;
* Chat ID;
* збереження Telegram-конфігурації;
* перевірка Telegram.

### Перевірка Telegram

Окрема кнопка **«Перевірити Telegram»** перевіряє всі введені Chat ID.

Наприклад:

```text
🟢 5211583667 — особистий чат: повідомлення доставлено
🟢 -5111414452 — група: повідомлення доставлено

🟢 Telegram працює: 2 з 2 чатів доступні.
```

При неправильному Chat ID:

```text
🟢 5201183667 — особистий чат: повідомлення доставлено
🔴 5141114452 — HTTP 400: Bad Request: chat not found

🟠 Telegram працює частково: 1 з 2 чатів доступні.
```

## 🔄 Скидання мережевих налаштувань

Для відновлення доступу до пристрою передбачена фізична кнопка скидання мережевих налаштувань.

### Підключення

Кнопка підключається між:

```text
GPIO 5 ─────┐
            │
          КНОПКА
            │
GND ────────┘
```

Тобто натискання кнопки замикає **GPIO5 на GND**.

Функція призначена для скидання мережевих налаштувань пристрою у випадку, коли потрібно повторно налаштувати підключення до мережі.

> ⚠️ GPIO ESP32 працюють із низькою напругою. Не підключайте мережеву напругу до GPIO.

## 🧩 Апаратна частина

Основою пристрою є ESP32.

Основні підключення:

| GPIO   | Призначення                           |
| ------ | ------------------------------------- |
| GPIO 4 | вхід контролю електропостачання       |
| GPIO 5 | кнопка скидання мережевих налаштувань |

## 💾 Збереження даних

Power Monitoring використовує NVS ESP32 для постійного зберігання даних.

Зберігаються:

* Bot Token;
* Chat ID;
* стан незавершеного відключення;
* час початку останнього відключення;
* час відновлення;
* тривалість відключення;
* кількість відключень;
* загальний час без електроенергії.

Після перезавантаження пристрій відновлює збережену інформацію.
